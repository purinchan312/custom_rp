# 統合ユーティリティRP (Unified Utility Resource Pack for Minecraft Bedrock)

Minecraft 統合版（Bedrock Edition）において、**実績（Achievements）を 100% 有効（ON）に保ったまま** サバイバル・マルチプレイ・Realms で利用できる純粋リソースパックです。

ビヘイビアーパック（BP）・スクリプトAPI・実験的機能（Experiments）・改造バイナリシェーダー（`.material.bin`）を一切使用せず、標準リソースパック仕様のみで3つの実用機能を1つのパックに統合しています。

---

## 主な機能

### 1. HUD常時チャンク座標 ＆ 日本語バイオーム名表示 (`rp01`)
オフハンドにアイテムを持たなくても、画面左上の座標エリア直下に以下の2段情報を常時表示します。

- **1段目（チャンク情報）**: `<チャンク内相対X(1〜16)>, <チャンク内相対Z(1〜16)> (<チャンクX>, <チャンクZ>)`
  - チャンク外周や四隅に立っている場合のみ、末尾に ` : 線` / ` : 左上` / ` : 右上` / ` : 左下` / ` : 右下` を自動表示（北＝上、西＝左基準）
- **2段目（バイオーム名）**: 現在地の公式準拠 **日本語バイオーム名**（オーバーワールド・ネザー・エンド・地下バイオームの全59種＋フォールバック対応）
- **他画面への非干渉**: 三人称視点のプレイヤーモデル、インベントリ画面、ポーズ画面、マルチプレイ時の他プレイヤー視点には一切映り込みません。

### 2. 防具立てによる3Dチャンク境界 ＆ MOB湧き範囲ビジュアライザー (`rp02`)
バニラの防具立て（`minecraft:armor_stand`）を設置し、**スニーク＋ポーズ変更** を行うことで3Dガイド表示を切り替えられます。

| ポーズ番号 | 切替回数 | モード表示 | 表示内容 |
| :--- | :--- | :--- | :--- |
| `0` / `3〜12` | 初期状態 / 3回以上 | 非表示（通常防具立て） | ガイド表示なし（拠点の装飾用防具立てに干渉しません） |
| `1` | スニーク＋操作 1回 | `[1] チャンク境界表示` | 設置チャンクの `16×16` 境界枠 ＋ 四隅ピラー（±48m） ＋ 16m毎のサブチャンク高さ枠 ＋ 北（`N`）マーカー |
| `2` | スニーク＋操作 2回 | `[2] チャンク＋湧き範囲 (24m安全 / 44m湧き)` | ポーズ1の要素 ＋ **半径24m未満 安全圏（緑）** ＆ **半径24〜44m MOB出現範囲（赤）** の1ブロック単位ジグザグ球体ワイヤー ＋ 地球儀回転経線 ＋ 半透明床グリッド |

- **段差ごとの正確な湧き潰し判定**: 丸い近似リングではなく、ワールドの1ブロック幅にスナップした角張ったジグザグ球体を全1m段差ごとに描画するため、斜面や段差でもブロック単位で湧き範囲内外を判別できます。
- **視線外れによる消滅防止**: ベースジオメトリの視錐台カリング境界（`visible_bounds`）を拡張済みのため、防具立てに背を向けたり足元の地面を向いて松明を設置したりしてもワイヤーが消えません。

### 3. 村人交易 全レベル（Lv1〜Lv5）事前解放 ＆ エンチャント確認 (`rp03`)
就職ブロックで就職した直後（Lv1 見習い）の村人に話しかけた時点から、取引画面のスクロールリストに **Lv1（見習い）〜 Lv5（達人）までの全5段階の取引スロット** を展開表示します。

- **未解放枠のエンチャント詳細ホバー表示**: 未解放レベル（Lv2〜Lv5）に並んでいるエンチャントの本やダイヤモンド装備にマウスカーソルを合わせる（またはタップする）と、付与されているエンチャント名とレベル（例: `修繕 I`、`効率強化 V` 等）を日本語ツールチップでそのまま確認できます。
- **UIプロファイル両対応**: ビデオ設定の「クラシック」「ポケット」の両方のUI構成に対応しています。
- ※ クライアント側の表示マスクのみを解除する仕組みのため、実績は維持され、未解放レベルの実際の購入ロック自体はサーバー側判定通り維持されます。

## サブパック（負荷・機能プリセット切替）

リソースパック適用画面の歯車（設定）アイコンから、用途や端末スペックに合わせて2段階のモードを切り替えられます。

1. **フル機能モード（デフォルト）**: HUDチャンク＆バイオーム表示 ＋ 防具立て3D視覚化 ＋ 村人交易全解放
2. **軽量モード**: HUDチャンク＆バイオーム表示 ＋ 村人交易全解放のみ（防具立て3D視覚化をOFF）

## 対応バージョン・ビルド環境

- **Minecraft 統合版（Bedrock Edition）**: `1.21.130` 以降
- **ビルド環境（ソースから `.mcpack` を生成する場合）**:
  - OS: Windows
  - `.NET 10 SDK`（C# 標準クラスライブラリのみ使用・サードパーティ NuGet パッケージ不使用）
  - `PowerShell`

## ビルド ＆ 導入手順

### ソースコードから `.mcpack` を生成する
リポジトリルート（または `src` ディレクトリ）から以下のコマンドを実行すると、テクスチャアトラス生成・3Dジオメトリ生成・構文/数式/セキュリティ自動検証・`.mcpack` パッケージング・オフライン検証HTMLレポート出力が一括実行されます。

```powershell
powershell -ExecutionPolicy Bypass -File .\src\build.ps1
```

ビルド完了後、`dist/` 配下に以下のファイルが出力されます（`dist/` および `*.mcpack` は `.gitignore` により Git 管理対象外です）。

- `dist/unified_utility_rp_v<version>.mcpack` — 配布・導入用リソースパック
- `dist/spec_verification_report.html` — 仕様実装・数式検算・テクスチャ実物確認レポート（完全オフライン / JavaScriptゼロ）

個別ステップのみ実行したい場合は `-Mode` パラメータを指定できます：

```powershell
powershell -ExecutionPolicy Bypass -File .\src\build.ps1 -Mode validate
# 指定可能モード: all | atlases | geometries | validate | pack | report
```

### Minecraft への導入方法
1. 生成（または Releases から取得）した `.mcpack` ファイルを開くと Minecraft が起動し、自動インポートされます。
2. ワールドの「編集」→「リソースパック」（または「設定」→「グローバルリソース」）から **統合ユーティリティRP** を有効化してください。

## ディレクトリ構成

```text
.
├── dist/                 # ビルド成果物出力先 (.gitignore 対象: .mcpack / 検証HTML)
├── specs/                # 各機能および共通アーキテクチャの仕様書 (.md)
├── src/
│   ├── build.ps1         # .mcpack 一括ビルド＆自動検証スクリプト
│   └── resource_pack/    # リソースパック本体アセット一式
└── tools/
    ├── NuGet.Config      # 外部フィード遮断設定 (<clear />)
    └── RpBuilder/        # アトラス生成・ジオメトリ生成・自動検証ツール (.NET 10 C#)
```

## セキュリティ・サプライチェーン方針

- **サードパーティ依存ゼロ**: ビルドツールは `.NET 10` 標準ライブラリ（BCL）と `PowerShell` のみで実装されており、`npm` や外部 NuGet パッケージへの依存は一切ありません。
- **完全オフライン動作**: `tools/NuGet.Config` にて外部パッケージソースを `<clear />` で遮断し、コード内・検証用HTML内ともに外部ネットワーク通信処理や外部URL参照を完全に排除しています。
