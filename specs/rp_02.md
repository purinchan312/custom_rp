# リソースパック仕様 #02: 防具立てによるチャンク境界・安全圏・MOB湧き範囲 3D視覚化

本仕様書は `rp_specs/00_RP_ARCHITECTURE.md` の共通規約に基づき、バニラの防具立て（`minecraft:armor_stand`）を使って「設置チャンクの $16 \times 16$ 境界ワイヤー」「その場所にプレイヤーが立った場合の安全圏（湧き禁止範囲）」「MOBが湧く範囲と水平ガイド面」を3D表示する機能を定義する。

---

## 1. 機能概要とポーズ切替操作（サバイバル・装飾両立設計）

* **機能プレフィックス**: `rp02`
* **基本設計**:
  * 拠点内の装飾用防具立てまで常時ワイヤー表示になるのを防ぐため、サバイバルで素手（スニーク＋右クリック／「ポーズ変更」）でいつでも切り替えられる **防具立てのポーズ番号 (`query.armor_stand.pose_index`, $0 \sim 12$)** をトリガーとして使用する。
  * ポーズ `0`（設置直後のデフォルト立ち姿）およびポーズ `4`〜`12` は **通常のバニラ防具立てと完全に同一の見た目** を維持する。

| ポーズ番号 | 切替回数（設置後スニーク＋操作） | モード名称（頭上ラベル日本語表示） | 表示される3Dガイド要素 |
| :--- | :--- | :--- | :--- |
| `0` | 初期状態（0回） | 通常（ガイド非表示） | なし（通常の防具立てのみ描画） |
| `1` | 1回 | `[1] チャンク境界表示` | 設置チャンクの $16 \times 16$ ワイヤーフレーム枠 ＋ 四隅ピラー ＋ $16$ マス毎のサブチャンク高さ枠 ＋ 北（`N`）方向マーカー |
| `2` | 2回 | `[2] チャンク＋湧き範囲 (Sim4/Realms標準)` | チャンク境界枠 ＋ **半径 $24\text{m}$ 安全圏（緑ワイヤー球＋床面緑グリッド）** ＋ **半径 $24\text{m} \sim 44\text{m}$ MOB湧き圏（床面赤乗算グリッド＋赤/橙ワイヤー球）** |
| `3` | 3回 | `[3] 広域湧き・デスポーン範囲 (Sim6+)` | ポーズ `2` の要素 ＋ **半径 $32\text{m}$ ランダムデスポーン開始球（黄ワイヤー）** ＋ **半径 $128\text{m}$ 即時デスポーン限界球（青ワイヤー）** |
| `4`〜`12` | 4回〜12回 | 通常ポーズ（ガイド非表示） | なし（通常の防具立てポーズ描画を維持） |

## 2. 座標スナップ補正と回転打ち消し計算式（重要）

防具立てをチャンク内の **どのブロックに・どの向きを向いて設置しても**、チャンク境界枠が正確にワールドのチャンクグリッドへ一致し、かつ湧き範囲球は「防具立てが立っているその座標（＝仮想プレイヤー立ち位置）」を中心に展開されるよう、アニメーション（`animations/rp02_chunk_visualizer.animation.json`）でボーン空間を分離制御する。

### 2.1 ルート回転打ち消しボーン (`viz_world_aligned_root`)
防具立ては設置時のプレイヤーの向きに応じて `query.body_y_rotation`（$45^\circ$ 刻み等）で回転している。すべての子ガイドボーンが正確に東西南北へ整列するよう、親ボーンで本体回転を打ち消す。
* 回転補正: `rotation = [0, -q.body_y_rotation, 0]`（モデル空間の回転符号に合わせて実機検証のうえ厳密に北が $-Z$ になる符号を設定すること）。

### 2.2 チャンク境界ケージ用ボーン (`chunk_cage_group`) の自動スナップ
`viz_world_aligned_root` の子ボーンとして配置し、防具立ての現在座標からチャンク北西角（$X_{\text{min}}, Z_{\text{min}}$）へのズレ量を逆算して平行移動させる（1ブロック ＝ $16$ モデル単位）。

* チャンク内オフセット量（ブロック単位）:
  $$\Delta X = \text{query.position}(0) - \lfloor \text{query.position}(0) / 16 \rfloor \times 16$$
  $$\Delta Z = \text{query.position}(2) - \lfloor \text{query.position}(2) / 16 \rfloor \times 16$$
* ボーン位置オフセット（モデルピクセル単位、モデル原点がチャンク北西角 $(0, 0)$ 基準の場合）:
  $$\text{position}_x = -\Delta X \times 16, \quad \text{position}_z = -\Delta Z \times 16$$
  ※ Bedrockのジオメトリ空間における $+X$（西/東）の軸向きに合わせ、防具立てをチャンク内の任意のマスに置いた際に $16 \times 16$（$256 \times 256$ モデル単位）の外枠線がブロック境界と完全に重なるよう符号を合わせること。
* 高さ方向の範囲: 防具立ての足元を基準に上下 $\pm 48$ ブロック分程度の縦ピラーと、防具立て足元チャンクの $16$ ブロック単位（$\lfloor Y / 16 \rfloor \times 16$）にスナップした水平サブチャンク枠線を描画する。

### 2.3 仮想プレイヤー湧き範囲ボーン (`player_spawn_sphere_group`)
こちらはチャンク角へスナップさせず、`viz_world_aligned_root` 直下の **防具立て自身の中心座標 $(0, 0, 0)$** を原点として配置する（プレイヤーをその防具立ての位置に立たせた場合の距離判定を再現するため）。

1. **安全圏（MOB自然スポーン禁止領域: $r < 24\text{m}$）**:
   * 半径 $24$ ブロック（$384$ モデル単位）の3軸ワイヤーフレーム球体（経線・緯線リングによる低ポリゴン球表現、エメラルドグリーン発光色）。
   * 防具立ての足元ブロック上面高さ（$Y = +0.02$ ブロック付近、Zファイティング防止の微小オフセット付き）に、半径 $0 \sim 24\text{m}$ の **半透明グリーンの1マス目盛り付き水平サークル面** を展開する。これにより、周囲の床ブロック上面に緑色の安全圏オーバーレイが重なって見える。
2. **MOB湧き危険圏（自然スポーン発生領域: $24\text{m} \le r \le 44\text{m}$）**:
   * 足元高さ（$Y = +0.02$ ブロック）における半径 $24\text{m} \sim 44\text{m}$ のドーナツ状リング領域に、**半透明レッド（乗算・アルファブレンド調の赤色警告グリッド、1ブロック単位の格子線入り）** の水平プレーンを展開する。
   * ※ 純粋リソースパックの仕様上、周囲ブロックの凹凸地形データを取得して各段差へ自動追従することはできないため、防具立てと同じY高さの水平基準面＋立体ワイヤー球（半径 $44\text{m}$ ＝ $704$ モデル単位の赤/オレンジワイヤー球）の組み合わせによって空間的・平面的に湧き範囲を判別させる。
3. **広域デスポーン球（ポーズ `3` 専用）**:
   * 半径 $32\text{m}$（$512$ 単位、黄色ワイヤー球）および半径 $128\text{m}$（$2048$ 単位、水色ワイヤー球）を追加表示する。

## 3. マテリアル定義と視錐台カリング（消滅現象）対策

### 3.1 カスタムエンティティマテリアル (`materials/entity.material`)
暗所のトラップタワー内部や夜間でもワイヤーと半透明面が鮮明に視認でき、かつ球体の内側から見ても裏面が消えないよう、`entity.material` に以下を定義する。

* **ワイヤー・ラベル用発光マテリアル (`rp02_wire_emissive:entity_emissive_alpha`)**:
  * 両面描画（`"+states": ["DisableCulling"]`）を有効化し、暗闇でも明るさ最大でくっきり線が見えるようにする。
* **床面カラーオーバーレイ用半透明マテリアル (`rp02_zone_translucent:entity_alphablend`)**:
  * 半透明アルファブレンドおよび両面描画（`"+states": ["DisableCulling", "Blending"]`、必要に応じて深度書き込み無効 `DisableDepthWrite`）を設定し、下のブロックのテクスチャが透けて乗算・オーバーレイ風に見える透明度（アルファ値 $25\% \sim 35\%$ 程度）でテクスチャを作成する。

### 3.2 視線を外した際のモデル消滅（Frustum Culling）防止対策
防具立てから $30\text{m}$ 離れて防具立てに背を向けながら $44\text{m}$ 境界線を確認する際、防具立て本体が画面外に出るとカリングによってガイド全体が消えてしまう問題を防ぐため、`models/entity/rp02_chunk_visualizer.geo.json` 内に **透明テクスチャを貼った極小サイズ（$0.01$）のバウンディングボックス拡張用アンカーキューブ** を広域四隅（例: $[\pm 1024, \pm 512, \pm 1024]$）に配置し、クライアントの描画判定ボックスを広げておくこと。

## 4. 受け入れテスト確認項目

- [ ] 防具立てを設置した直後（ポーズ `0`）は通常の防具立てとして表示され、既存の拠点装飾に一切影響しないこと。
- [ ] スニーク＋操作でポーズ `1` にすると頭上に `[1] チャンク境界表示` が現れ、チャンク内のどのマス・どの角度で防具立てを置いても、`rp01` のHUDチャンク端判定（`1` と `16` の境目）と $16 \times 16$ ワイヤー枠が1ピクセルのズレもなく一致すること。
- [ ] ポーズ `2` で緑の $24\text{m}$ 安全圏ワイヤー＆床面オーバーレイと、赤の $24\text{m} \sim 44\text{m}$ 湧き範囲床面グリッド＆$44\text{m}$ ワイヤー球が表示され、暗い洞窟内でもはっきり視認できること。
- [ ] 防具立てから $30\text{m}$ 離れて横や後ろ（境界線側）を向いても、ワイヤー表示が途中でパッと消えないこと。
